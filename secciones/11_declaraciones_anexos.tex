\item Anexo D: cálculos y simulaciones.

Los parámetros del modelo térmico de primer orden se obtienen a partir del
coeficiente global de pérdidas térmicas $UA$, la masa activa de fluido y el
calor específico del agua. Estos parámetros corresponden al modelo del
proceso y no a los parámetros de sintonía del controlador.

El valor de la ganancia estática del proceso se calcula como:

\begin{equation}
K = \frac{1}{UA}
= \frac{1}{4}
= 0{,}25\ \mathrm{K/W}
\end{equation}

La constante de tiempo del proceso se determina mediante:

\begin{equation}
\tau = \frac{m\,c_p}{UA}
= \frac{15 \times 4186}{4}
= 15\,697{,}5\ \mathrm{s}
\approx 261{,}6\ \mathrm{min}
\end{equation}

Por tanto, el modelo de primer orden utilizado para representar la dinámica
térmica del sistema queda definido por:

\begin{equation}
\boxed{
G(s) = \frac{0{,}25}{15\,697{,}5\,s + 1}
}
\end{equation}

A partir del valor de $UA$ también pueden determinarse las potencias de
régimen permanente requeridas para las dos temperaturas de operación
consideradas. La potencia necesaria para compensar las pérdidas térmicas se
calcula mediante:

\begin{equation}
Q_{ss} = UA\,\Delta T
\end{equation}

Para el prelavado, con una diferencia de temperatura de $\Delta T=30$ K,
se obtiene:

\begin{equation}
Q_{ss} = 4(30) = 120\ \mathrm{W}
\end{equation}

Considerando una resistencia de calentamiento de $1500$ W, el ciclo de
trabajo requerido en régimen permanente es:

\begin{equation}
D = \frac{Q_{ss}}{P_{\max}}\times100
= \frac{120}{1500}\times100
= 8{,}0\,\%
\end{equation}

Para la fase de lavado, con una diferencia de temperatura de
$\Delta T=20$ K:

\begin{equation}
Q_{ss} = 4(20) = 80\ \mathrm{W}
\end{equation}

y, por tanto, el ciclo de trabajo correspondiente es:

\begin{equation}
D = \frac{80}{1500}\times100
= 5{,}33\,\%
\end{equation}

En consecuencia, los principales parámetros obtenidos para el modelo y los
puntos de operación son:

\begin{equation}
\boxed{
K=0{,}25\ \mathrm{K/W},
\qquad
\tau=15\,697{,}5\ \mathrm{s}\approx261{,}6\ \mathrm{min}
}
\end{equation}

\begin{equation}
\boxed{
\begin{aligned}
\text{Prelavado:}\quad &Q_{ss}=120\ \mathrm{W},
&&D=8{,}0\,\%\\
\text{Lavado:}\quad &Q_{ss}=80\ \mathrm{W},
&&D=5{,}33\,\%
\end{aligned}
}
\end{equation}
